# safe-variable-name

> Get a safe variable name from a given string.

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add safe-variable-name

# 使用 yarn-tool / Using yarn-tool
yarn-tool add safe-variable-name
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add safe-variable-name

# 使用 pnpm / Using pnpm
pnpm add safe-variable-name

# 使用 npm / Using npm
npm install safe-variable-name
```
