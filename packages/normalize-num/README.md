# normalize-num

> Normalize numbers in strings, including Roman numerals and circled numbers

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add normalize-num

# 使用 yarn-tool / Using yarn-tool
yarn-tool add normalize-num
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add normalize-num

# 使用 pnpm / Using pnpm
pnpm add normalize-num

# 使用 npm / Using npm
npm install normalize-num
```
