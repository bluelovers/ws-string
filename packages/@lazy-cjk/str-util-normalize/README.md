# @lazy-cjk/str-util-normalize

> Remove invisible Unicode characters and normalize strings

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/str-util-normalize

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/str-util-normalize
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/str-util-normalize

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/str-util-normalize

# 使用 npm / Using npm
npm install @lazy-cjk/str-util-normalize
```
