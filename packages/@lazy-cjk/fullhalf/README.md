# @lazy-cjk/fullhalf

> Converts character to full-width/half-width character.

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/fullhalf

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/fullhalf
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/fullhalf

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/fullhalf

# 使用 npm / Using npm
npm install @lazy-cjk/fullhalf
```
