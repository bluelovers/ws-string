# crlf-normalize-stream

> Transform stream for normalizing newline characters (CR/LF/CRLF)

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add crlf-normalize-stream

# 使用 yarn-tool / Using yarn-tool
yarn-tool add crlf-normalize-stream
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add crlf-normalize-stream

# 使用 pnpm / Using pnpm
pnpm add crlf-normalize-stream

# 使用 npm / Using npm
npm install crlf-normalize-stream
```
