# num-is-roman

> Check if a string is a Roman numeral

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add num-is-roman

# 使用 yarn-tool / Using yarn-tool
yarn-tool add num-is-roman
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add num-is-roman

# 使用 pnpm / Using pnpm
pnpm add num-is-roman

# 使用 npm / Using npm
npm install num-is-roman
```
