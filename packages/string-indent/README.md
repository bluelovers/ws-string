# string-detect-indent

> Simple detect string indent

## 安裝 (Installation)

```bash
# 使用 yarn / Using yarn
yarn add string-detect-indent

# 使用 yarn-tool / Using yarn-tool
yarn-tool add string-detect-indent
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add string-detect-indent

# 使用 pnpm / Using pnpm
pnpm add string-detect-indent

# 使用 npm / Using npm
npm install string-detect-indent
```
